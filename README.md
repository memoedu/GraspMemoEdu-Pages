# GraspMemoEdu 网站发布

正式入口：https://memoedu.github.io/GraspMemoEdu-Pages/

本仓库发布公开静态前端。业务源码与导出工具维护于 [memoedu/GraspMemoEdu](https://github.com/memoedu/GraspMemoEdu)。开发、测试后从源码仓库发布已验证版本，不在此单独修改生成的业务文件。

旧入口保留浏览器身份迁移页。邀请码账号可重新登录以读取原有服务器进度；游客从旧入口点击“保留进度并进入”，通过限定来源的浏览器消息迁移身份及草稿。身份不进入 URL、Git 或服务器日志，原站副本保留。

协作流程见 [CONTRIBUTING.md](CONTRIBUTING.md)。
