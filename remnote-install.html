安装 RemNote 配套工具

使用已登录的网站账号下载安装包。需要 Windows x64、Google Chrome 和 RemNote 桌面端。

  1. 解压整个安装包，双击 Install.cmd。安装完成后，窗口会显示本机扩展目录。
  2. 在 Chrome 地址栏输入 chrome://extensions，开启「开发者模式」，点「加载已解压的扩展程序」，选择刚才显示的 extension 目录。
  3. 打开要关联的 RemNote 知识库，进入「设置 → 插件 → Build」，用 Develop from localhost 添加 http://localhost:43153/ 的导航插件，再添加 http://localhost:43103/ 的正文插件。保持沙箱模式，按提示授权。已安装的插件可直接启用。
  4. 回到原 Topic 并刷新，在正文工具栏点击「在本地 RemNote 中打开」，用当前网站账号配对。已绑定的 Document 会在后台同步。点击 RemNote 窗格右上角的「打开 GraspMemoEdu」可回到同一 Topic，回跳使用 Windows 的默认浏览器，请在那里登录绑定账号。

若提示账号不一致，请切换到这个知识库原来绑定的网站账号。
